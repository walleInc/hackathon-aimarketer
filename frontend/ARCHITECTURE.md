# Frontend

Simple FSD: app → pages → widgets → entities → shared. Each slice exposes index.ts; import slices through their public API. No same-layer dependencies between widgets or pages. UI primitives generated by shadcn/ui live in shared/ui. Shared API provides authenticated transport; entities/marketing owns endpoint contracts and Zod schemas. Each editor uses react-hook-form with zodResolver. Theme tokens in app/styles.css use the supplied HEX palette.

Node.js 22+ (see .nvmrc).

npm ci
npm run dev
npm run build
npm run test:e2e

Add UI components: npx shadcn@latest add <component>

Browser tests mock the API and cover saved settings across tabs, mobile overflow, Zod validation, task submissions and company-admin limits. Run `npx playwright install chromium` once. Registry components Input and Textarea use forwardRef for React 18 compatibility; preserve this when regenerating them.
